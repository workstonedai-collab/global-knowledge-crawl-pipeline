# 字段与配置 / Templates and configuration

[中文指南](../README.zh-CN.md) · [English guide](../README.en.md)

## 配置文件 / Configuration files

JSON 无需第三方依赖；YAML 需要 `yaml` 可选依赖。所有配置中的文件路径均相对于配置文件目录；工作目录由 `--workspace` 指定，默认相对于启动位置的 `runtime/<dataset>`。 / JSON needs no external dependencies; YAML needs the `yaml` extra. File paths inside configuration are relative to the config file. `--workspace` controls state and output; its default is `runtime/<dataset>` relative to the launch directory.

| 字段 / Key | 含义 / Meaning |
| --- | --- |
| `dataset` | 独立数据集标识，字母、数字、连字符和下划线 / Separate dataset identifier, using letters, numbers, hyphens, underscores |
| `offline` | 为 true 时硬性阻止网络请求 / Block network requests when true |
| `template` | 字段模板文件 / Field template file |
| `sources` | URL、RSS/Atom、列表来源 / URL, RSS/Atom, listing sources |
| `search` | 可选的关键词检索配置 / Optional keyword search |
| `fetch` | 正文提取设置与可选 fixture 映射 / Body fetching and optional fixture map |
| `enrichment` | 富化适配器 / Enrichment adapter |
| `limits` | 每次运行限制 / Per-run limits |
| `incremental_overlap_hours` | 增量时间窗向前重叠小时数，默认 24 / Incremental overlap, 24 hours by default |
| `output_formats` | `csv`、`xlsx`、`jsonl` / Export formats |
| `allow_private_network` | 默认 false；仅对自己控制的本地/私有服务启用 / Default false; enable only for local/private services you control |

`validate` 检查主要配置结构和模板，不联网测试凭据、接口兼容性、网页授权或可达性。 / `validate` checks the main structure and template. It does not contact services to test credentials, protocol compatibility, source permissions, or reachability.

## 来源 / Sources

```json
{
  "id": "public-updates",
  "name": "My public updates",
  "type": "listing",
  "url": "https://example.com/updates",
  "include_pattern": "/news/",
  "allow_external": false
}
```

- `id` 必须在配置内唯一。`type` 为 `url`、`rss` 或 `listing`。 / IDs must be unique. Types are `url`, `rss`, or `listing`.
- `url` 来源直接创建候选；`rss` 解析 RSS/Atom；`listing` 提取列表中的链接。 / URL sources create candidates directly; RSS sources parse feeds; listings extract links.
- 可选 `keywords` 为标题和摘要的大小写不敏感包含筛选，任一关键词命中即可。 / Optional `keywords` match substrings in titles/snippets case-insensitively, with OR semantics.
- `include_pattern` 对发现的完整 URL 进行正则筛选。请使用受控、简单的表达式。 / `include_pattern` filters full discovered URLs by regex; use controlled, simple expressions.
- `allow_external` 默认 false，列表页只跟随同一主机的链接。 / External listing links are excluded by default.
- `fixture` 从本地读取列表或 feed，用于离线演示；正文 fixture 使用 `fetch.fixtures` 按规范化 URL 映射。 / `fixture` loads listing/feed content locally; body fixtures are mapped by canonical URL in `fetch.fixtures`.

## 字段模板 / Field templates

```json
{
  "version": "my-template-v1",
  "fields": [
    {"name": "标题", "type": "string", "source": "metadata.title", "required": true},
    {"name": "summary", "type": "string", "instruction": "Summarize in Chinese, preserving uncertainty.", "required": true, "evidence_required": true},
    {"name": "category", "type": "string", "instruction": "Classify the article.", "enum": ["product", "policy", "other"]}
  ]
}
```

字段名必须为有效标识符、唯一且不以下划线开头。JSON 字段名必须与 AI 返回键一致。类型支持 `string`、`integer`、`number`、`boolean`、`array`、`object`；数组可配置 `items_type`。对象内部结构不在当前校验范围内。 / Names must be valid unique identifiers and must not begin with an underscore. AI response keys must match them. Types include string, integer, number, boolean, array, and object; arrays can set `items_type`. Object internals are not validated in this version.

元数据映射支持 `metadata.title`、`metadata.url`、`metadata.published_at`、`metadata.source_name`、`metadata.snippet`。这些字段不需要 AI 生成。 / Metadata mappings support title, URL, publication time, source name, and snippet. They are not generated by AI.

`required` 检查非空值；`enum` 检查允许值；`evidence_required` 要求非空 AI 字段有正文中的证据摘录。错类型或错枚举值在输出中置空并附带原因。程序不把模型“信心分数”当作事实可靠性。 / Required fields are checked for nonempty values; enums restrict allowed values; evidence requirements demand excerpts for non-null AI fields. Invalid types/enums become null with reasons. Model confidence scores are not treated as factual reliability.

模型返回结构 / Expected enrichment envelope:

```json
{
  "fields": {"summary": "A proposal, not a confirmed launch.", "category": "product"},
  "evidence": {"summary": ["A launch date has not been confirmed."], "category": ["a new product proposal"]}
}
```

证据摘录必须是程序实际提供给模型的正文中的精确子串，每条最多 500 字符。摘要不必与摘录逐字一致，但程序也无法验证摘要的全部语义。 / Each excerpt must be an exact substring of the text actually supplied to the model and no longer than 500 characters. The summary need not copy the excerpt; its complete semantics are not verified.

## 默认限制 / Default limits

| 配置 / Limit | 默认值 / Default |
| --- | ---: |
| `max_items` | 50 |
| `max_search_requests` | 10 |
| `max_ai_calls` | 20 |
| `max_http_requests` | 200 |
| `max_total_tokens` | 100000 |
| `max_output_tokens` | 1200 |
| `max_attempts` | 3 |

`max_items` 分别限制本次新增候选数和本次处理尝试数，不限制历史导出总行数。正文重复候选的抓取也计入处理尝试。 / The item limit applies separately to newly added candidates and processing attempts during the run, not historical export rows. Fetching an exact-body duplicate also counts as a processing attempt.

`fetch` 可配置 `timeout_seconds`、`max_response_bytes`、`min_text_chars`、`respect_robots` 和 `provider`。超时限制在 1–120 秒，响应上限最多 10 MB；默认分别为 20 秒、2 MB、40 字符、遵守 robots、`http`。 / Fetch settings include timeout, response-byte limit, minimum text length, robots behavior, and provider. Timeout is clamped to 1–120 seconds and size to 10 MB. Defaults are 20 seconds, 2 MB, 40 characters, robots enabled, and HTTP.

`enrichment.max_text_chars` 默认 12000；正文被截断时结果进入复核，并保留截断标记。 / Enrichment input defaults to 12,000 characters. Truncation marks the result for review.
