GLOBAL KNOWLEDGE CRAWL PIPELINE · BY GKN

把你关心的信息，整理成一张表。Turn the information you follow into your own table.

填写来源、关键词和目标字段，预览配置后下载两个文件。此页面完全在本机运行，不发起采集、不调用 AI，也不收集密钥。
Choose sources, keywords and fields, then download your configuration. This page works locally without crawling, calling AI or collecting credentials.

1. 信息来源 / Sources

有关键词时需要搜索接口；没有关键词时只采集网址。/ Keyword searches require a search API; otherwise only URLs are collected.

2. 服务与预算 / Services and budget

配置只记录环境变量名：GKP_ENRICH_API_KEY、GKP_SEARCH_API_KEY。请让你的 agent 帮你设置实际密钥。
Configuration contains environment variable names only. Ask your agent to help set your actual credentials.

3. 你希望表格包含什么 / Your table fields

标题和来源网址自动加入。下面字段由 AI 提取，要求提供原文摘录。/ Title and source URL are included automatically. AI fields below require source excerpts.

4. 预览与下载 / Preview and download

上表仅预览列名称，运行后才会出现真实结果。example.com 地址是占位符，需要替换。/ This is a column preview. Actual records appear after running. Replace example.com placeholders.

完整配置 / Full configuration
把两个下载文件放在同一文件夹。在该文件夹中运行 / Place both files in one folder and run there:
python3 -m gkp validate config.json
python3 -m gkp run config.json
python3 -m gkp run config.json --refresh-existing
打开 runtime/<dataset>/output/evidence.html 查看结果与证据。搜索服务默认约定为 POST {query,since,limit} → {results:[{url,title,description,published_at}]}，其他返回格式请按 adapters 文档修改映射。
Open output/evidence.html in your dataset workspace. The default search mapping expects the contract above; customize it following the adapters guide.
